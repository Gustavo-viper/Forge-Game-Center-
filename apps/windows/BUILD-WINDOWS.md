# Forge Game Center — Windows

## Gerar o EXE
1. Instale Node.js LTS.
2. Entre nesta pasta: `apps/windows`
3. Execute `npm install`
4. Execute `npm run dist`
5. O instalador `.exe` será criado em `apps/windows/dist/`.

O aplicativo empacota apenas a Central. Os jogos continuam abrindo em seus respectivos navegadores.
