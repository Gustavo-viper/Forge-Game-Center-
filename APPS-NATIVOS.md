# Aplicativos nativos Forge Game Center

A pasta `apps/android` contém o projeto Android Studio para gerar o APK.
A pasta `apps/windows` contém o projeto Electron para gerar o instalador EXE.

Os dois aplicativos são somente a Central. Cyber Detective, Hangman Pro e os demais jogos continuam abrindo no navegador.

Observação: os binários finais APK/EXE precisam ser assinados/compilados em um ambiente com Android SDK e/ou toolchain Windows. Os projetos estão prontos para a geração dos binários.
